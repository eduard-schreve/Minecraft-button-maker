# Minecraft-button-maker
This repo is designed to make 2 separate images (one of the button and one of the button while the mouse is hovering over it) 

Please note that the only way to alter the original size and text on the buttons is in the code on line 11 and line 33 respectively!!!

Altering size: press your left mouse button and the buttons will change to that size (more of a debug feature for me)

Saving: press your right mouse button to save this will create 2 images in the folder you're running this in (one of the button and one of the mouse hovering over it)
